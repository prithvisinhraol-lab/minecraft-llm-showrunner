# Malevolent Shrine Upgrade Design

## Goal

Upgrade the Nether Crater Shrine at `900 86 -360` so it reads closer to a cursed shrine domain: a black temple-gate silhouette, bone-like ribs, maw-like portal center, and fully treated crater walls.

## Visual Direction

- Keep the build original and inspired by the mood, not a direct replica.
- Add a temple-like dark roof/crown behind the portal using blackstone, deepslate, crimson, and gilded accents.
- Add pale rib or antler forms with bone blocks and calcite so the shrine has the recognizable skeletal silhouette.
- Add pointed dripstone teeth around the portal opening to create a maw-like center.
- Convert the crater walls from plain terrain into layered cursed walls with blackstone, deepslate, basalt, soul soil, purple glass glow pockets, crying obsidian, and crimson vein accents.
- Increase dark purple lighting with amethyst, purple stained glass, end rods, candles, and crying obsidian.

## Functional Requirements

- Preserve the existing usable Nether portal at the shrine core.
- Preserve the safe entrance and viewing path at `900 84 -392`.
- Keep edits bounded around the existing shrine so nearby builds are not affected.
- Save the world after construction and verify the portal still exists.
